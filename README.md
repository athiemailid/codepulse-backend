1. Install ngrok
•	Download from ngrok.com
•	Unzip and place the executable in a folder included in your PATH, or run it from your project directory.

2. Start Your Local API
•	Run your ASP.NET API app in Visual Studio.
•	Note the port (e.g., https://localhost:7294).

3. Start Ngrok (Open a terminal and run)
   ngrok http https://localhost:7294
